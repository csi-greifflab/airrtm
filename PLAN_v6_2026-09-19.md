# PLAN v6 -- LR decay on the best recipes (2026-09-19)

## The premise, and its one weakness

`lr_decay_gamma: null` in **every config this project has ever run**. Two independent
pieces of evidence say that is a real default bug rather than a neutral choice:

1. **`rangeloss_depth1`'s loss shape.** Train `total` converges by ~epoch 46 (1.23 ->
   1.18 over the next 55 epochs, a 4% move) while val `total` bottoms at epoch 36 and
   climbs to 1.83 by epoch 120; train-val gap widens 0.28 -> 0.49. Overfitting past a
   converged optimum, with no instability anywhere -- the textbook case for a schedule.
2. **`rangeloss_depth1_lrdecay` (gamma 0.97) held its train-val gap at 0.013 across 80
   epochs**, where every other run on the board opened 0.29-0.57, and its best val
   `label` (0.3259) came at **epoch 78** -- the only mature run here still improving at
   its budget. The constant-LR parent was at ~0.43 by epoch 80; `lr1e3` reached 0.67.

**The weakness: all of that is the label loss, not held-out AUC.** This document records
repeatedly that training metrics do not predict the curve -- `tm10x` had the best label
loss and the best reconstruction ever recorded and sat at its untrained floor. So the
decay arm's own curve (running now) gates how far this plan goes.

## Bars

LR decay does not change initialisation, so each arm inherits its parent's untrained bar:

| family | untrained bar |
|---|---|
| `normloss_tm03_nowarm` (T=30, attention, count^2, depth 4) | **0.6842 +/- 0.0247** |
| `rangeloss_depth1` (depth 1) | **0.6633** |

Nothing counts as a result unless it clears its own bar, and epoch-to-epoch noise on
these curves is ~0.04.

## Stage 0 -- launched 2026-09-19, GPUs 6/7

| run | change from parent | why |
|---|---|---|
| `tm03_nowarm_lrdecay_seed239` | `lr_decay_gamma: null -> 0.97` | decay on the 0.7904 recipe |
| `tm03_nowarm_lrdecay_seed1` | same, seed 1 | seed spread here is brutal (0.762 / 0.754 / 0.710 on one config) |

80 epochs, `checkpoint_every: 2`, everything else byte-identical to
`config_normloss_tm03_nowarm_seed239.yaml`. ~7 h train + ~1.5 h curve.

Two seeds, not one gamma sweep: a single seed of this family cannot be distinguished from
noise, and gamma 0.97 keeps it comparable to the depth-1 arm already measured.

## Stage 1 -- the gate (curves land ~2026-09-19 15:30)

Six curves are scoring now. Three readings decide Stage 2:

| reading | question | threshold |
|---|---|---|
| **R1** | `rangeloss_depth1_lrdecay` vs its constant-LR parent (0.7544 / 0.7269, bar 0.6633) | **>= 0.79** clear win; 0.72-0.79 inconclusive; **< 0.72** decay hurts |
| **R2** | do `normloss_tm03_nowarm_seed{1,2,3}` replicate 0.7904 (bar 0.684)? | **mean >= 0.76** the record stands; **mean <= 0.73** it was a seed |
| **R3** | `rangeloss_depth1_lr1e3` | expected below parent; confirms the direction |

R2 matters as much as R1: if the record does not replicate, Stage 0's parent is not
actually the best recipe and Stage 2's arms change with it.

## Stage 2 -- six GPUs, branch on R1

### Branch A -- decay wins (R1 >= 0.79, or Stage 0's two seeds both clear +0.08)

| GPUs | arms |
|---|---|
| 2 | `tm03_nowarm_lrdecay_seed{2,3}` -- four seeds total, the minimum for a real claim |
| 2 | gamma bracket at seed 239: **0.93** (0.055x LR by ep40) and **0.99** (0.67x) |
| 2 | decay on the second-best recipe: `normloss_nowarm_lrdecay_seed{239,1}` (parent 0.7666, +0.083) |

### Branch B -- decay is a null on AUC (R1 inconclusive or < 0.72)

Then decay flattens the label loss without moving the thing we care about, and the plan
falls back to the one lever never swept:

| GPUs | arms |
|---|---|
| 6 | `vae_coef` **0.15 / 0.3 / 0.5** on the 0.7904 recipe, two seeds each |

Every run in this project used `vae_coef: 0.05`. It is PLAN_v5 Stage 2, written and never
executed, and the direct lever on `rec_acc`. Gate: `rec_acc` >= 0.7 **and** margin >= +0.08.

### Either branch -- one GPU if a slot frees

`freetheta_seqlabel` rerun with **phi bounded** (`topic_l1_coef > 0`, currently 0
everywhere, `weight_decay` also 0 everywhere). Arm A's premise -- free Theta forces the TM
gradient into phi -- was never tested: phi inflated instead (`phi_l2` 0.2 -> 57) and the
run went NaN at epoch 54 while `tm` sat at chance the whole time. If that arm is rerun,
the entropy coefficients must also go to 0, or the `notm` control is not a control.

## Standing rules for this batch

1. **80 epochs, `checkpoint_every: 2`.** 200-epoch budgets made the leader worse
   (0.7666 -> 0.7583); everything past ~70 has been a decaying tail.
2. **Every arm gets a checkpoint-AUC curve. No arm is judged on training metrics.**
3. **Report every margin against the arm's own untrained bar**, not against 0.684 by
   default -- T and depth change the bar.
4. **One change per arm.** The one exploratory two-change arm
   (`rangeloss_nowarm_depth1`) is still ambiguous between range mode and depth.
5. **No capacity increases.** Width 64->128 at both depths, heads 8->2, T 30->300 and a
   bigger encoder were all neutral or harmful; the only decrease (depth 4 -> 1) produced
   the best margin in the project.
